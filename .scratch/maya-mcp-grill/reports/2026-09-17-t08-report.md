## 契约落位

- snapshot: M3dView.active3dView → VP2 img.create(kFloat)→readColorBuffer→convertPixelFormat(kByte)（官方补丁，否则全黑）→verticalFlip→temp PNG→QImage 降采样→JPEG/PNG base64。cmds.refresh(force=True) 前置。
- preview: playblast 单帧 format=image/compression=png/offScreen/viewer=False/showOrnaments=False/percent=100/forceOverwrite/editorPanelName=钉面板；widthHeight 服务端向上取整 ÷4；completeFilename+glob 兜底解析。
- 返回: [ImageContent(audience=[assistant,user]), TextContent(JSON {session,camera,panel,width,height,format,bytes[,source:playblast]})]。
- headless 双闸: 宿主 framed_channel==False → GuiSessionRequiredError（isError，零往返）；Maya 侧 about(batch)/无 modelPanel/omui-PySide 缺失 → {error:{code:gui_session_required}}。
- 服务端校验: data_b64 非空 + magic 与 format 匹配（capture_empty/capture_invalid）。
- 净零副作用: _look_thru_restored（原相机 modelEditor -q -camera 读回→lookThru→finally 恢复+面板存活校验+失败仅告警）+ currentTime save/restore（防 undo bug #21）。六条副作用披露已写入 scene_render_preview docstring。
