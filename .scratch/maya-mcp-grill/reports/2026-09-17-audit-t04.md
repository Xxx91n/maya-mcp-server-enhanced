## §3 必修清单（打回项；修完重跑 §1 全套验收）

**F-1【D-019 spec-partial】宿主侧失败未全量化 code。**
- session_manager.py:259/264/271 三处裸 ValueError（无会话/多会话/会话未找到）——13+ 个需会话工具与 2 个 resource 全部可达；实测 stdio 返回 "No Maya sessions available. Use add_session first." 无 [code]。
- server.py:421 `ClientType(client_type)` 裸 ValueError（add_session 坏类型）；client.py:580 `raise TypeError(client_type)`；server.py:109 RuntimeError（manager 未初始化）。
- spec 原文：ADR-0011「宿主侧失败（参数校验/限流/**连接**/管线拒绝）抛类型化异常」。
- 修法建议：新增 SessionLookupError(PipelineError)（如 code="session_unavailable"/"invalid_input"），或复用 maya_unavailable；ClientType 解析包一层 InputValidationError。改动 ~15 行。

**F-2【文档失真/AGENTS 联动硬违】threat-model.md §5 与 TOOL_ANNOTATIONS 矛盾。**
- §5 L74-76 把 camera_create/camera_orbit/scene_checkpoint 列在 destructive；代码三者均 _WRITE_SAFE(destructiveHint=false)——ADR-0005 与代码一致，**文档错**。同条还漏列其余 5 个 _WRITE_SAFE/add_session 的 idempotent=false。文档自身说 "See pipeline.TOOL_ANNOTATIONS for the full matrix"——自指打脸。修法：按 pipeline.py:56-78 重写 §5 矩阵。

**F-3【审计不变式破口】_resolve_session_id 在 try 外。**
- pipeline.py:134 先于 try/finally；FastMCP Context.session_id 在 request_context=None 时 raise RuntimeError（已读库源码确认）→ 崩溃逃审计+无 code。stdio 下有 context 故低可达，但 in-process/无 transport 调用真实存在。修法：移入 try 或对 session_id 取值加 try/except 落 "_default"。

**F-4【零误杀边界】file-traversal 规则 `..` 宽于 spec 的 `../`。**
- security.py:321 re.compile(r"..") 对 filename 类参数任意位置两个点即 block（"v1..2.ma"、"report..final.ma" 误杀）——违反 D-018「block 仅留零误杀精确规则」。修法：收紧为 `..[\/]` 或 `(^|[\/])..([\/]|$)`。

## §4 建议同轮修复（小改、强化 spec 意图）

- **F-5** AuditLogger.record 写文件失败时 early return 先于 logger.info——"双写"形同虚设：文件一坏两条流全丢；且 _disabled 一次瞬时失败即永久静默（security.py:526-544）。建议 logger 写无条件化 + 去掉单次失败永久 latch（或计次/节流告警）。
